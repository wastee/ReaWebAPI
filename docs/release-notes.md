# ReaWebAPI

## English

- Fix mouse pointer restoration over REAPER native windows after typing in a Windows WebView2 text field, preserving hide-while-typing behavior.
- Fix Linux floating-window resize stalls and improve WebView size synchronization and display scaling.
- Fix Linux docking transition flicker and window style handling, preserving visibility and Docker position.

## 简体中文

- 修复 Windows WebView2 文本输入后鼠标光标在 REAPER 原生窗口上移动时无法恢复的问题，保留输入时隐藏光标的行为。
- 修复 Linux 浮动窗口调整大小时的卡顿，改进 WebView 尺寸同步和显示缩放处理。
- 修复 Linux 停靠切换时的闪烁和窗口样式异常，保留可见状态与停靠位置。

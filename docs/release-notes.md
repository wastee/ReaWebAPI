# ReaWebAPI

## English

- Add a resizable ReaWebAPI page under Preferences > Plug-ins with a Use sRGB for WebView rendering checkbox and Restore defaults button.
- Apply the sRGB override through WebView2 on Windows after restarting REAPER. Keep native color management on macOS and Linux, with the checkbox disabled.

## 简体中文

- 在 Preferences > Plug-ins 下新增随页面尺寸调整的 ReaWebAPI 设置页，提供 Use sRGB for WebView rendering 复选框和 Restore defaults 按钮。
- Windows 通过 WebView2 请求固定 sRGB，重启 REAPER 后生效。macOS 和 Linux 保留原生色彩管理，复选框禁用。

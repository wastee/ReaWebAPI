# ReaWebAPI

## English

- Add persistent, shared JSFX editor content sizing through `jsfx.editor`, with native window adaptation on Windows, macOS and Linux.
- Restore the requested size before presenting chain and floating editors, including scales below 100%.

## 简体中文

- 新增 `jsfx.editor` 内容尺寸接口，支持持久保存、同一 JSFX 关联的实例同步及 Windows、macOS、Linux 原生窗口适配。
- 在显示 FX 链和浮动编辑器前恢复请求的尺寸，支持低于 100% 的缩放。
